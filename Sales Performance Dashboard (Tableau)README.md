# Sales Performance Dashboard (Tableau)

## Project Goal
Create interactive dashboards to track sales performance, revenue trends, and KPIs across regions and product categories. Designed for business stakeholders to make data-driven decisions.

## Dataset
- Public “Sample Superstore” dataset (CSV)
- Columns include Order Date, Region, Product Category, Sales, Profit, Customer Name, etc.

## Steps / Code Overview
1. Clean dataset using Python (handle nulls, date conversion, deduplication).  
2. Export cleaned CSV for Tableau.  
3. Connect Tableau to CSV and create interactive dashboards:  
   - KPIs: Total Sales, Total Profit, Avg Order Value  
   - Filters: Region, Product Category, Year  
   - Charts: Sales trends over time, top products, regional performance  
4. Highlight actionable insights (e.g., top-performing products and regions).

## Tools & Technologies
- Tableau  
- Python (Pandas) for data cleaning  
- Excel / CSV

## Key Learnings
- Learned to create dynamic, filterable dashboards.  
- Improved skills in calculating KPIs and using LOD expressions.  
- Gained experience presenting actionable insights from raw data.
